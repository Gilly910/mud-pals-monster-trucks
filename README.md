# Mud Pals Monster Truck Rally

A tap-and-drive monster truck learning game for toddlers (ages 3–4), built for iPad. Single self-contained HTML file — no build step, no data collection.

## Play

- **Online:** https://kguillie.github.io/mud-pals-monster-trucks/
- **Local:** open `index.html` in any modern browser.

## iPad setup

1. Open the Pages link in Safari.
2. Share → **Add to Home Screen** for a full-screen app icon.
3. Optional: Settings → Accessibility → **Guided Access** to lock the iPad to the game.
4. Tap once on the start screen to enable sound (iOS requires a tap before audio plays).
